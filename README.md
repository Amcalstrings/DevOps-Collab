# DevOps GitHub Collaboration Lab

This repository is used for practicing real-world Git and GitHub collaboration.

## What students will practice

- Cloning a shared repository
- Creating feature branches
- Making commits
- Pushing changes to GitHub
- Opening Pull Requests
- Reviewing code
- Resolving collaboration issues

## Class Rule

No one should push directly to the main branch.

All changes must go through:

Branch → Commit → Push → Pull Request → Review → Merge
